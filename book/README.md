# Same Object, Different Meaning: A Guide to Persuasion, Identity, and Design

This is a short guide exploring how persuasion, brand archetypes, and design language work together — both as tools for shaping how a product is perceived, and as a control framework for directing AI-assisted creative and technical work.

## How to Use This Guide

Read the chapters in order. Chapters 1–3 introduce each lens on its own. Chapter 4 applies all three lenses to a single running example — a plain white t-shirt sold four different ways. Chapter 5 draws the lenses together into a general framework, including how they apply to working with AI.
